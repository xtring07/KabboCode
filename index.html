Rules of KABBO CODE

  1. Six bits per code. Each assigned character or signal uses exactly six binary digits.
  2. Separate groups. Put a space between each six-bit group when sending encoded text.
  3. Spaces are encoded. A normal text space uses 100010. Separating code groups is different.
  4. Supported characters only. Unsupported characters, such as £, are flagged.
  5. Valid code groups. Each group must contain exactly six digits, using only 0 and 1.
  6. Special tokens. START, END, ERROR, REPEAT, and @Kabbo use their assigned codes when entered as standalone tokens.
  7. Same codebook. The sender and decoder must use the same official assignments.

KABBO CODE is a text encoding system, not encryption. Encoding changes how text is represented but does not by itself keep messages secret.
